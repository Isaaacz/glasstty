# Wallpapers

The five wallpapers glasstty is shown with. They are not part of the code and
are not covered by the project's GPL-3.0 licence: each belongs to its author.

| File | Source |
|---|---|
| `liquid-metal.jpg` | unknown author |
| `eva-01.jpg` | Evangelion Unit-01 fan art, unknown author |
| `night-car.jpg` | BrabusBodo wallpaper pack |
| `f40.jpg` | [wallhaven d8vvlo](https://wallhaven.cc/w/d8vvlo) |
| `katana.jpg` | [wallhaven p8rxz9](https://wallhaven.cc/w/p8rxz9) |

If you are the author of one of these and want it credited differently or
removed, open an issue.

Any image works: the colours of the whole desktop come from whichever
wallpaper you pick (`Super+W`), so you can replace these with your own:

```bash
rm -f ~/Pictures/wallpapers/*
cp /path/to/your/images ~/Pictures/wallpapers/
```
